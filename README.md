# JunimosWearHats

Junimos from the junimo hut now wear whatever hat you put inside the hut. This works for mod added hats too, though not fashion sense hats.

This mod also adds these gameplay tweaks, as a treat:
1. When the junimos are wearing hats, they will work outside in the rain and winter.
2. If they don't finish during the day, junimos will pull overtime and harvest within the hut's range overnight.
3. When the junimos have raisins (which you can see by the little sign), their harvest radius will increase from 8 tiles to 10 tiles.

## Installation

1. Download and install SMAPI.
3. Download this mod and install to the Mods folder.

## Configuration

- `Enable_WorkInRainAndWinter`: Toggle whether hats allow junimos to work in rain and winter.

- `Enable_HarvestAllAtEndOfDay`: Toggle whether junimos pull overtime.

- `Enable_RaisinsIncreaseRadius`: Toggle whether snacks make the junimos work harder.
